## Overview

Soundtoys EchoBoy is the most comprehensive delay plugin available, emulating over 30 vintage delay hardware units from tape echoes to digital delays with authentic character per model.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Soundtoys EchoBoy** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **30+ Styles** | Emulations of Space Echo, Echoplex, Memory Man, and many more |
| **Rhythm Echo** | Pattern-based rhythm delay with per-tap level and feedback |
| **Dual Mode** | Independent left and right delay for wide stereo echo effects |
| **Saturation** | Per-style tape and analog saturation matching the original hardware |
